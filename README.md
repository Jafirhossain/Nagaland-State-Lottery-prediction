# 🏆 Nagaland State Lottery — Master Intelligence Studio v9.0

A professional, high-performance web application designed for advanced statistical analysis, human-like 7-layer gap-cycle prediction, auto red-marker hit verification, and official gazette archiving for Nagaland State Lotteries (Lottery Sambad).

---

## ✨ Key Features

* **🎯 Time-Slot Routed Predictions:** Dedicated analytical panels for **1:00 PM (Dear Morning)**, **6:00 PM (Dear Day)**, and **8:00 PM (Dear Night)** draws.
* **🧠 7-Layer Human-Like Logic:** Analyzes Overdue Mean Gaps, Cross-Slot Transitions, Palta (Reverse), Mirror Twins (`0↔5, 1↔6`), Neighbor Steps (`±1`), and Prize Tier Gravity.
* **🔴 Auto Red-Marker Hit Verification:** Automatically cross-checks algorithmic predictions against official winning numbers and highlights hits with animated red markers.
* **🏛️ Official Gazette Portal View:** Interactive result sheets mirroring official gazette formats, complete with 1st Prize, ₹10,000, ₹500, ₹250, and ₹120 prize tiers.
* **📥 Printable PDF & CSV Exporter:** Instantly generate and download official Gazette-style `.PDF` result sheets or export full historical data as `.CSV`.
* **🔍 Instant Ticket Checker:** Test any 2-digit or 4-digit ticket number against archive records to calculate real-time win probability and past hit frequencies.
* **📄 Vision OCR & Multi-Proxy Scraper:** Built-in support for scanning official result PDFs and image screenshots using Tesseract.js.

## 🚀 Quick Setup & Deployment

Since this is a fully client-side static application contained in a single master file (`index.html`), you can deploy it instantly on **Cloudflare Pages** or **Vercel** with zero backend configuration:

1. Create a repository on GitHub (e.g., `nagaland-master-studio`).
2. Upload the `index.html` file into the root of your repository.
3. Go to **Cloudflare Dashboard** -> **Workers & Pages** -> **Create application** -> **Pages** -> **Connect to Git**.
4. Select your repository, leave build settings empty, and click **Save and Deploy**!
